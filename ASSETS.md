# Original assets and provenance

LANDFALL 64 uses no third-party game artwork, samples, recordings, fonts, music, character names, maps, ROMs or game code.

All visible artwork is generated by the drawing functions in `index.html`: the island coastline, trees, fortifications, soldiers, vehicles, helicopter, landscapes, aircraft, naval ships, gun decks, interface and projectile effects. Typography uses the system's existing monospace font. No font is bundled or downloaded. The two naval bonus games reuse genre mechanics described in the historical Beach-Head manual, with their own names, visuals, encounters, code and sound.

All sound is generated locally with Web Audio. `voiceSamples()` creates new vowel cries using harmonics weighted around vocal formants, a pitch glide, seeded breath noise and sample quantization. `mathSamples()` creates an original rhythmic pulse using a mathematical note sequence, oscillators and seeded noise. Weapon and interface sounds use short oscillator envelopes. No sound is sampled from another game or person.

The palette and pixel resolution evoke historical home computers; the artwork, arrangements, story, level layouts and wave equations are original to this project. No affiliation with another game's creators is implied.
